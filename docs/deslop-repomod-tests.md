A hosted mutation check of the publication scope is **advisory**, not required. This checkout has no such job, and its selection, negative controls, runner cost and retention were never qualified, so nothing may rely on it. Publication is protected today by the ordinary suite (`make repomod-test`), which runs in PR CI:

- **Refusal and branch movement:** `test_fix_push.py` `test_fix_push_reports_publication_refusals` covers an invalid fix ref, wrong origin, dirty checkout, missing or advanced default branch, missing or moved fix ref and a missing remote default, each asserting the result and that local refs, remote refs and the working tree are unchanged. `test_fix_push_refuses_changed_canonical_identity` covers a canonical commit or branch change before and during the remote query; `test_push_fix_branch_skips_when_remote_default_advanced`, `test_fix_push_rejection_preserves_both_branch_tips` and `test_push_rejection_keeps_local_commit_and_never_rewrites_remote` cover remote movement and rejected pushes; `test_push_uses_checked_commit_when_checkout_changes_before_push` and `test_fix_push_uses_validated_commit_when_branch_moves` cover the commit that is pushed.
- **Unchanged canonical checkout:** `test_fix_command.py` `test_fix_publishes_only_from_unchanged_canonical_checkout` runs `fix` with and without a user commit during fixing: it publishes one branch and one pull request when unchanged and publishes nothing otherwise. `test_fix_safety.py` covers a concurrent canonical edit or commit (`test_canonical_change_during_fix_preserves_commits_on_fix_branch`, `test_concurrent_canonical_commit_is_never_overwritten`), dirty, non-default-branch and diverged checkouts (`test_unfixable_checkout_states_are_skipped_without_modification`, `test_fixer_refuses_untracked_files_hidden_by_display_settings`) and two concurrent runs (`test_two_concurrent_fix_runs_create_only_one_commit`).
- **Path admission:** `test_fix_safety.py` `test_invalid_plan_and_symlink_target_are_rejected` and `test_fixer_rejects_invalid_paths_before_writing` reject malformed plans, symlink targets, absolute, parent-relative, backslash and out-of-scope paths before writing.
